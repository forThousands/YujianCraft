# Swordflight

Minecraft 1.20.1 / Forge 47.4.22 的原创材料飞剑模组原型。

当前版本 `0.7.5` 提供可玩的材料、战斗、可逆改造与视听表现闭环：

- 模组独立创造分页中的木、石、铁、金、钻石、下界合金六种飞剑；
- 右键召唤六柄飞剑，再次右键全部收回；
- 模式 A：背后扇形停靠，径向出剑、上升、追击；
- 模式 B：背后竖直环形停靠，直接追击；
- 模式 C：使用正确剑尖轴的扇形阵，飞行路径与模式 A 相同；
- `Ctrl+R` 切换阵型，可在原版“按键绑定”界面重新设置；
- `Ctrl+I` 打开服务端同步配置面板，每项设置都有独立恢复默认按钮；
- 普通设置可启用肩后优化第三人称：玩家偏左、屏幕中央显示细线准心；相机保持原始连续朝向，屏幕中心射线统一负责方块拾取、生物高亮和飞剑锁定，目标不会吸附或牵动准心；远距离生物直接设置光灵箭所用的客户端共享发光位，近距离方块显示白色边框；
- 优化相机使用从玩家视点到肩后位置的完整连续轨道，不再继承原版第三人称离散缩放；遇墙时连续收缩，离墙后平滑展开，在极狭窄空间临时隐藏本地玩家模型以避免后脑遮挡；
- 自动索敌，或使用准心持续 0.75 秒主动锁定目标；
- 主动锁定目标头顶显示红色倒三角，准心持续指向新目标可切换；
- 手持飞剑左键可立即锁定准心附近目标；
- 单次出击，或穿出更远后沿侧上方弧线折返，持续穿刺到目标死亡；
- 飞剑离阵飞行时使用原版鞘翅循环声塑造破空感，按速度调节音量和音高，并限制远距及同时声源数量；
- 飞行尾迹使用客户端位置历史批量绘制三层全亮剑光，不产生网络粒子；外层材质色辉光、中层提亮色和白热核心共同强化灵力速度感，木、石、铁、金、钻石和下界合金分别使用集中配置的材质色；
- 剑身全亮、光灵箭式轮廓、物品附魔闪光和破空声/尾迹均可在开发者选项“视听实验”分页独立开关及恢复默认；
- 飞剑默认使用所有材质辨识度更强的原版像素剑模型；飞行实体沿原版剑自身的斜向长轴延伸约 22%，不改变物品栏和正常手持外观；剑身外不再使用交叉亮片，而是包裹由四组截面和八个侧面组成、剑尖连续收束的扁菱形立体剑罡，内部具有白热剑脊，并有一段带软边的高亮灵力从剑柄持续流向剑尖；停靠时流速克制，高速飞行时加速，出剑瞬间光壳扩张并增强；先前 OBJ 仙侠长剑仅作为铁质实验备份保留在开发者选项中；
- 开启作弊的房主或 OP 可按材质调整服务端伤害与飞行速度；
- 飞剑拥有高于原版的分材质耐久，攻击命中会消耗耐久，并可在原版铁砧使用对应材料修复；
- 新增“飞剑工作台”：工作台置于中央、八颗钻石环绕合成；
- 工作台支持火纹、引雷、蚀毒、爆裂、箭雨、锋锐、固本和不毁八类可逆模块；
- 三级模块使用 `1 / 16 / 64` 份材料安装为 I / II / III，拆除时完整返还安装材料；
- 命中特效共享按目标计算的服务端冷却，引雷和爆裂不会破坏方块；
- 开发者配置提供“飞剑参数 / 效果参数 / 索敌与停靠 / 视听实验”分页和左侧类别列表，每个参数或实验开关均可单独恢复默认；
- 命中后先顺势穿出，再经玩家后上方的安全回剑走廊归位；
- 待机朝向由阵型决定，飞行时剑尖始终朝向速度方向；
- 伤害和目标判定均由服务端执行，支持多人游戏继续扩展。

## 开发环境

- Minecraft 1.20.1
- Forge 47.4.22
- Java 17
- Gradle 8.8（Wrapper 已配置 SHA-256 校验）

系统上已有 Microsoft JDK 17 时，可在 PowerShell 中构建：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Microsoft\jdk-17.0.12.7-hotspot'
.\gradlew.bat build
```

正式成品使用版本号命名并归档到不会被 Gradle 清理的 `releases`，例如 `releases/swordflight-0.6.1.jar`。`build/libs` 只是临时构建输出。

启动开发客户端：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Microsoft\jdk-17.0.12.7-hotspot'
.\gradlew.bat runClient
```

进入创造模式后，从“御剑工艺”分页取得任意材质飞剑。每种配方均为对应原版剑置于中央、八颗钻石环绕。

## 材质与配方管理

材质清单集中在 `FlyingSwordMaterial`。物品注册、创造分页、显示模型和配方数据均遍历这一清单生成；以后增加材质时，只需登记原版基剑、耐久与默认战斗属性，不必复制六套配方文件。

| 材质 | 基础耐久 | 铁砧修复材料 |
| --- | ---: | --- |
| 木 | 384 | 任意木板 |
| 石 | 768 | 圆石 |
| 铁 | 1536 | 铁锭 |
| 金 | 512 | 金锭 |
| 钻石 | 3072 | 钻石 |
| 下界合金 | 4096 | 下界合金锭 |

## 飞剑工作台

工作台左侧分页选择模块，每一项直接显示其注册材料图标；中央放入飞剑和模块材料，右侧从模块数据动态显示材料名称、各等级消耗并执行安装或拆除。放入 1、16、64 份材料会自动选择 I、II、III；下界之星“不毁”只有一级。替换或拆除模块会把旧材料优先退回玩家背包，背包满时掉落在玩家脚边。改装会自动收回同材质的已召唤剑阵，避免实体继续使用旧模块快照；重新右键召唤即可应用新属性。

| 材料 | 模块 | 作用 |
| --- | --- | --- |
| 烈焰粉 | 火纹 | 施加独立“剑灼”状态，等级控制时长和每秒伤害 |
| 避雷针 | 引雷 | 每级增加一道视觉闪电，并按每道配置伤害结算 |
| 毒马铃薯 | 蚀毒 | 施加独立“剑蚀”状态，等级控制时长和每秒伤害 |
| 火药 | 爆裂 | 产生爆裂视听效果和可调伤害，不创建破坏方块的爆炸 |
| 箭 | 箭雨 | 从目标上方生成数量可调的实体箭 |
| 绿宝石 | 锋锐 | 增加飞剑直接命中伤害 |
| 钻石 | 固本 | 增加最大耐久；改装时按剩余耐久比例平滑换算 |
| 下界之星 | 不毁 | 写入原版兼容的不毁标记，不再消耗耐久 |

模块注册、材料阈值和类别集中在 `FlyingSwordModule`；数值项集中在 `EffectParameter`，命中触发集中在 `SwordEffectEngine`。新增模块时无需复制工作台菜单逻辑。

## 运动结构

阵型坐标和回剑航路点集中在 `FormationGeometry`，飞行阶段集中在 `FlightPhase`，实体只负责按阶段推进。模式 A/C 的阶段为：停靠 → 向外净空 → 上升 → 追踪 → 穿出 → 回剑集结点 → 停靠入口 → 停靠；模式 B 跳过“向外净空”和“上升”。模式 A 保留早期偶然形成的侧向视觉，模式 B/C 使用校正后的真实剑尖轴。

当前使用动态航路点与转向加速度，不使用方块寻路。飞剑无碰撞且主要在空中移动，引入 A* 会产生不必要的抖动和性能开销；以后需要绕建筑时，可以在现有阶段间增加射线检测和局部避障阶段。

停靠状态在服务端精确绑定阵位；客户端根据玩家与飞剑的同一渲染帧插值重新计算显示阵位，避免两个网络实体插值不同步造成拖拽抖动。高速攻击使用运动线段与目标碰撞箱相交判定，不依赖物品模型本身的碰撞。

## 战斗设置同步

`Ctrl+I` 面板打开时先向服务端请求当前飞剑设置，收到回包后按钮才可操作。所有战斗与效果数值由服务端限制并持久化；客户端只保存界面状态和服务端同步快照，因此可用于多人游戏。效果面板可调整统一触发冷却、剑灼/剑蚀时长与伤害、单道雷击伤害、无方块破坏的爆裂伤害、箭雨数量与伤害，以及锋锐/固本各级增量。

首次启动客户端会生成 `config/swordflight/client-options.json`。`optimizedThirdPerson` 由游戏内按钮维护；`showDeveloperOptions` 默认为 `false`，需要手动改为 `true` 并重新打开配置界面，才会向拥有 OP 2 级权限的玩家显示“开发者选项”。最短停靠时间、自动索敌半径和准心锁定距离已从普通设置移入此处；服务端仍会校验权限，修改 JSON 不能绕过 OP 限制。

## 原创边界

本项目只采用“可操控的悬浮武器”这一通用玩法概念，不使用现有作品的专有名称、角色、剧情、造型、阵法名称或特效设计。后续内容将围绕 Minecraft 的材料、附魔、锻造与怪物生态建立独立设定。
