# Swordflight / 御剑工艺

面向 Minecraft 1.20.1 Forge 的原创御剑战斗模组。以原版材料、锻造与附魔语言为基础，提供可召回的飞剑阵列、主动或自动索敌、御剑飞行和可逆模块装配。

> 当前版本：`0.9.16`（开发预览版）
> 运行环境：Minecraft `1.20.1`、Forge `47.4.22`、Java `17`

## 主要内容

- 木、石、铁、金、钻石、下界合金六种材质，以及对应的灵铸系列。
- 六柄战斗飞剑组成的三种阵型；模式 A 正向扇形阵为默认阵型。
- 默认使用准心主动锁定，也可切换自动索敌或“神识御剑”。
- 单次出击与持续穿刺两种攻击方式，飞行时剑尖跟随运动方向。
- 背包中拥有飞剑即可双击空格御剑飞行，承载剑与战斗剑阵相互独立。
- 飞剑工作台支持可逆安装火纹、引雷、蚀毒、爆裂、箭雨、锋锐、固本、不毁和熔金剑心。
- 火纹边缘火星、引雷短电弧、蚀毒雾迹、爆裂脉冲和箭雨风纹会随已安装模块动态出现。
- 命中具有短促闪光、冲击环和分层声音反馈；多模块同时安装时只选择一个主要音色，避免声音堆叠。
- 材质色剑光、灵力尾迹、破空声、剑罡与白热能量表现，并针对光影自动采用柔和亮度。
- 肩后优化第三人称、屏幕中心准心射线、远距离生物轮廓与近距离方块高亮。
- 服务端负责目标判定、伤害和平衡参数，支持多人游戏与管理员配置。

## 安装

1. 安装 Minecraft 1.20.1 与 Forge 47.4.22。
2. 将发布页中的 `swordflight-<版本>.jar` 放入该游戏实例的 `mods` 文件夹。
3. 客户端与服务器使用相同版本；本模组不是纯客户端模组。

开发预览版可能调整物品数据、配置格式与平衡数值。更新前建议备份世界。

## 快速开始

1. 合成任意基础飞剑并放在主手，右键召唤六柄飞剑；再次右键收回。
2. 默认“准心锁定”模式下，将准心指向生物并左键锁定。
3. 按 `Ctrl+R` 切换阵型；按 `Ctrl+I` 打开设置。
4. 在设置中启用御剑飞行后，只要背包中有飞剑，双击空格即可起飞或落下。

以上为默认按键；可在 Minecraft 的“选项 → 控制 → 按键绑定”中修改。

## 战斗模式

### 阵型

| 顺序 | 阵型 | 行为 |
| --- | --- | --- |
| A（默认） | 正向扇形阵 | 剑尖轴正确；出剑后先向外净空、抬升，再追击目标 |
| B | 环形阵 | 飞剑位于玩家侧后方环形边缘，可直接向前追击 |
| C | 侧锋扇形阵 | 保留早期版本形成的特殊侧向视觉，飞行路线与模式 A 相同 |

阵型保存为稳定名称而非显示顺序，因此本次 A/C 对调不会把已有物品的外观静默改成另一套阵型；没有阵型数据的新飞剑默认使用模式 A。

### 索敌

| 顺序 | 模式 | 行为 |
| --- | --- | --- |
| 1（默认） | 准心锁定 | 手持飞剑左键锁定准心目标；不会自动吸附或计时切换目标 |
| 2 | 自动索敌 | 在配置半径内选择可攻击目标 |
| 3 | 神识御剑 | 左键放出当时已停靠且冷却完成的飞剑，以视角引导；右键锁定准心目标 |

友伤开启且服务器规则允许时，主动锁定可以选择其他玩家。

### 攻击

- 单次出击：每柄飞剑命中一次后，经安全回剑航路返回阵位。
- 持续穿刺：飞剑穿过目标后继续前出，再沿弧线折返，直到目标死亡或失效。

## 合成

基础飞剑统一使用十字配方：对应原版剑放在中央，上、下、左、右各放一份锻材。

| 飞剑 | 中央物品 | 四周锻材 |
| --- | --- | --- |
| 木质飞剑 | 木剑 | 橡木木板 ×4 |
| 石质飞剑 | 石剑 | 圆石 ×4 |
| 铁质飞剑 | 铁剑 | 铁锭 ×4 |
| 金质飞剑 | 金剑 | 金锭 ×4 |
| 钻石飞剑 | 钻石剑 | 钻石 ×4 |
| 下界合金飞剑 | 下界合金剑 | 下界合金碎片 ×4 |

对应基础飞剑由八枚紫水晶碎片环绕，可进一步合成灵铸飞剑。两个系列共享耐久、战斗平衡和模块系统。

飞剑工作台配方：工作台置于中央，四个边位放铁锭，四角放紫水晶碎片。基础飞剑的材料也用于铁砧修复；木质飞剑可用任意木板修复。

所有配方集中维护在 `devtools/control_panel/recipes.json`，开发台和 Forge 数据生成器读取同一份清单，避免手工复制配方文件。

## 飞剑工作台与模块

工作台中的模块可安装、替换和拆除，拆除时返还材料。三级模块通常按 `1 / 16 / 64` 份材料安装为 I / II / III；单级模块只消耗一份材料。

界面右侧使用与实战相同的飞剑实体渲染管线进行实时预览。放入模块材料后会先显示预计外观；拖动可旋转，滚轮可缩放，闲置后自动缓慢旋转。

| 材料 | 模块 | 命中或属性效果 |
| --- | --- | --- |
| 烈焰粉 | 火纹 | 施加独立剑灼效果 |
| 避雷针 | 引雷 | 召唤不破坏方块的视觉闪电并结算可调伤害 |
| 毒马铃薯 | 蚀毒 | 施加独立剑蚀效果 |
| 火药 | 爆裂 | 产生不破坏方块的爆裂效果与可调伤害 |
| 箭 | 箭雨 | 从目标上方生成实体箭 |
| 绿宝石 | 锋锐 | 提升直接穿刺伤害 |
| 钻石 | 固本 | 提升最大耐久，改装时按剩余比例换算 |
| 下界之星 | 不毁 | 停止消耗耐久 |
| 熔岩块 | 熔金剑心 | 将剑身转化为白热能量表现 |

命中特效对同一目标共享服务端冷却，避免持续穿刺时高频触发造成卡顿。贯心真伤已从 0.9.13 起完全移除；本模组不通过直接改写生命值规避其他模组的 Boss 机制。

## 设置与多人游戏

`Ctrl+I` 中的普通选项包括索敌方式、攻击方式、第三人称、御剑飞行、飞剑光效和亮度档。

首次启动会生成 `config/swordflight/client-options.json`。将其中的 `showDeveloperOptions` 改为 `true` 并重新打开界面后，拥有 OP 2 级权限的玩家可以看到开发者选项。开发者页面可调材质伤害、飞行倍率、效果数值、索敌半径、最短停靠和视听实验；五种模块外观、命中反馈与工作台预览均有独立开关。

- 伤害、目标、效果和管理员平衡参数由服务端执行或校验。
- 相机、准心显示、亮度和本地视听实验属于客户端表现。
- 光影开启时自动切换为柔和亮度；仍可手动关闭光效或选择其他亮度档。

高亮、闪烁或光影叠加可能造成眼睛不适；光敏性癫痫风险者应关闭相关效果，如有不适立即停止使用。

## 开发

使用 Java 17：

```powershell
./gradlew.bat build
python -m unittest discover -s devtools/control_panel -p "test_*.py" -v
```

构建完成后，版本化成品保存在 `releases/swordflight-<版本>.jar`；`build/libs` 是临时输出。

双击根目录的 `启动御剑开发台.bat` 可打开本地可视化控制台，统一编辑材质、战斗、效果、御剑、视听默认值与合成配方，并执行版本递增、构建、归档、测试游戏安装和 SHA-256 校验。详细说明见 [devtools/control_panel/README.md](devtools/control_panel/README.md)。

仓库主要目录：

| 路径 | 内容 |
| --- | --- |
| `src/main` | Java 源码与手工资源 |
| `src/generated` | 数据生成器产物 |
| `devtools/control_panel` | 本地可视化开发台与配方唯一清单 |
| `art/source` | 模组贴图源文件 |
| `concepts` | 设计概念图，不打包进模组 |
| `tools` | 可重复生成视觉资源的辅助工具 |

版本变化见 [CHANGELOG.md](CHANGELOG.md)。

## 原创边界与协议

本项目只使用“可操控的悬浮武器”这一通用玩法概念，不采用现有作品的专有名称、角色、剧情、阵法名称、造型或素材。设计围绕 Minecraft 的材料、锻造、附魔和生物生态独立展开。
