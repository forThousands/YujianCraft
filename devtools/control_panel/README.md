# 御剑开发台

这是 SwordFlight 项目内置的本地可视化开发控制台，不依赖 npm、Electron 或第三方 Python 包。

双击项目根目录的 `启动御剑开发台.bat` 后，程序会在本机回环地址启动临时服务并自动打开浏览器。关闭启动器终端即可关闭服务。

当前可统一编辑：

- 六种飞剑的基础耐久、穿刺伤害、飞行倍率和灵光颜色；
- 最短停靠时间、自动索敌半径与准心锁定距离；
- 灼烧、引雷、蚀毒、爆裂、箭雨和属性强化的全部默认参数；
- 御剑水平速度、上升速度、下降速度与双击空格判定窗口。
- 全部模组合成配方：支持有序/无序合成、3×3 槽位、产物数量、分类、新建、复制与删除。

合成表以 `recipes.json` 作为唯一的可视化清单。九宫格中的每个已占用槽位会消耗一个对应材料；同一种材料需要多个时，直接把它放入多个槽位。保存时会同步生成 Minecraft 配方 JSON 与配方解锁进度 JSON，Forge 数据生成器也读取这份清单，避免后续运行数据生成任务覆盖可视化修改。

“保存数值”会校验范围并写回对应 Java 默认值。每次写入前都会在被 Git 忽略的 `backups` 目录建立源码备份。

“保存并构建下一版本”会依次执行：

1. 保存并校验全部可视化参数；
2. 按修订版、功能版或大版本规则递增三段式版本号；
3. 执行 Gradle 完整构建与重混淆；
4. 生成 `releases/swordflight-<版本>.jar`；
5. 可选地备份测试游戏中的旧 JAR，并安装新版本；
6. 对归档和安装文件执行 SHA-256 校验。

Forge 会保留已有世界 `serverconfig` 中的服务器覆盖值。界面中的“测试世界同步”是显式可选操作，只同步材质伤害、飞行倍率和命中特效；默认不会修改任何世界。

运行后端测试：

```powershell
cd devtools\control_panel
python -m unittest -v test_server.py
```
